# Bài tập Cơ sở lập trình

Repository lưu trữ bài tập thực hành môn Cơ sở lập trình.

## Cấu trúc thư mục

- `Buoi01/`: Bài tập buổi 1.
  - `Buoi01_A1/`: Project bài tập A1.
  - `Buoi01_B2/`: Project bài tập B2.
- `Buoi02/`: Bài tập buổi 2.
- Các thư mục `BuoiXX/` tiếp theo sẽ được bổ sung theo từng buổi học.

## Công nghệ sử dụng

- C#
- .NET
- Git và GitHub

## Mục đích

Quản lý mã nguồn, lưu trữ và theo dõi quá trình thực hiện các bài tập trong môn học.
